
# Bank Management System — Week 7

## Описание

Учебное консольное банковское приложение на Java.
Проект демонстрирует коллекции, обработку исключений и сохранение данных в CSV-файлы.

## Возможности

- Регистрация клиентов
- Открытие банковских счетов
- Пополнение и снятие средств
- Поиск клиентов и счетов
- Сортировка клиентов и счетов
- Сохранение и загрузка данных
- Проверка некорректных операций и данных

## Технологии

- Java 17+
- Collections Framework
- `try-catch`
- Собственные исключения
- `Path` и `Files`
- CSV-хранилище

## Структура данных

После первого запуска создаётся каталог `data/`:

- `customers.csv` — ID, имя, email
- `accounts.csv` — номер счёта, ID клиента, баланс

В учебной версии значения полей CSV не должны содержать запятые.

## Запуск

1. Открой папку проекта в IntelliJ IDEA.
2. Убедись, что выбран JDK 17 или новее.
3. Запусти класс `Main`.
4. После выполнения проверь каталог `data/`.
5. Запусти программу ещё раз, чтобы проверить загрузку сохранённых данных.

## Ограничения

Это учебная модель, а не реальная банковская система.
CSV не обеспечивает транзакционность и безопасную конкурентную запись.
В дальнейшем файловое хранилище можно заменить базой данных и JDBC.

## Темы недели

- Исключения и собственные типы исключений
- `try-with-resources`
- Чтение и запись файлов
- Коллекции `Map`, `Set`, `List`
- Сортировка через `Comparator`
- Разделение бизнес-логики и хранения данных
