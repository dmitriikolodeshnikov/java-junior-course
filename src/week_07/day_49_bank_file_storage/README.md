
# Week 7 — Exceptions and File I/O

## Цель

Научиться обрабатывать ошибки, создавать собственные исключения
и сохранять данные в файлы.

## Дни

- Day 43 — базовая обработка исключений
- Day 44 — `throw`, `throws`, собственные исключения
- Day 45 — `try-with-resources`
- Day 46 — `Path` и `Files`
- Day 47 — формат CSV
- Day 48 — надёжное файловое хранилище
- Day 49 — Bank Management System с сохранением данных

## Как работать

Каждый день содержит отдельный учебный проект.
Открывай нужную папку в IntelliJ IDEA и запускай `Main`.

`day-49-bank-file-storage`

Подробные требования и инструкция находятся в README итогового проекта.
