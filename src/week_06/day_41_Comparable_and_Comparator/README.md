# Day 41 — Comparable и Comparator

## Цель

Научиться сортировать объекты.

## Изучил

- Comparable
- compareTo()
- Comparator
- comparing()
- comparingInt()
- comparingDouble()
- reversed()
- List.sort()

## Мини-проект

Product Sorting.

## Главное различие

Comparable:
естественный порядок объекта.

Comparator:
внешнее правило сортировки.
