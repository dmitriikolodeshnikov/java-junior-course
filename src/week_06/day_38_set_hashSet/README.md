# Day 38 — Set и HashSet

## Цель

Научиться хранить уникальные элементы.

## Изучил

- Set
- HashSet
- уникальность
- equals()
- hashCode()
- contains()
- add()
- remove()

## Мини-проект

Unique Users.

## Важное правило

Если equals() считает два объекта равными,
их hashCode() должен быть одинаковым.
